# Changelog

## June 2026 — Initial documentation release

This documentation supersedes the Postman collection previously shared with
partners. The API itself is unchanged — this release formalises the existing
endpoints into a Swagger 2.0 spec and publishes them as an interactive reference.

### What's new
- Swagger 2.0 spec published
- Interactive API reference (Swagger UI)
- Sandbox available on request (Mockoon)

## Upcoming
We are actively working on our API and will be releasing changes over the coming months.

### Things we are working on
- Migration from Swagger 2.0 to OpenAPI 3.1.0 — no breaking changes expected
- Endpoints are subject to change in the next 6–12 months as we prepare API v2 (e.g. standardising naming conventions)
- Base URL migration from `tenantId.opusdentalonline.com` to `api.opusdental.com` in v2
- Authentication via Bearer token in v2 — API key authentication remains supported until then

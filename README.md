# Opus API (v1)

The Opus API gives authorised partners programmatic access to dental clinic data
including bookings and appointments, patient journals, invoices and insurance records. Access is available
to vetted partners under a signed data agreement.

**Base URL:** `https://[tenantID].opusdentalonline.com/api/public/v1`

## API Reference

The OpenAPI specification can be downloaded directly:
[openapi.json](openapi.json)

Or you can view the full interactive API reference in the Swagger UI:
[opus-dental.github.io/api-docs](https://opus-dental.github.io/api-docs/)

## Getting access

To request access to the API:

1. Contact us to discuss your use case: [contact form](https://www.opusdental.com/no/opus-support/kontakt-oss)
2. Sign a data processing agreement with Opus
3. Receive your API key and onboarding documentation


## Authentication

All requests require an API key.


## Status and versioning

This API is version v1 and is currently in active use. Endpoints and response formats may change over the next 6–12 months and any breaking changes will be communicated ahead of time in the [changelog](docs/changelog.md) with reasonable notice.

> [!WARNING] Do not build production systems on these endpoints without discussing stability
> commitments with Opus first.

## Sandbox

A sandbox environment is available for testing. Partners will be given the access
during the onboarding process.
